# slopsoil — .NET edition (in development)

A .NET 10 re-implementation of slopsoil's Jellyfin features, developed alongside the Python bot.
Spec, plan and tasks: [`specs/001-dotnet-rewrite/`](../specs/001-dotnet-rewrite/).

The Python bot remains the shipping application (`ghcr.io/briggsyj/slopsoil:latest`) until the parity
checklist passes; the .NET edition will publish as `:dotnet` first.

## Build and test

```bash
cd dotnet && ci/test.sh
```

Needs the .NET 10 SDK plus `libsodium` and `libopus` (Debian/Ubuntu: `libsodium23 libopus0`).
`ci/test.sh` runs the suite with coverage and fails below 90 % line coverage (P/Invoke shims in
`Slopsoil.Discord/Native/` and the host are excluded from the gate).

Protocol code is checked byte-for-byte against the Python implementation using vectors generated by
`tests/vectors/make_vectors.py` (run from the repository root; commit the regenerated
`tests/Slopsoil.Tests/Vectors/vectors.json`).

## Layout

| Project | Role (Python equivalent) |
|---|---|
| `Slopsoil.Common` | config, redaction, permissions (`permissions.py`, `redact.py`) |
| `Slopsoil.Discord` | gateway, voice, go-live, RTP, crypto, DAVE (`discord.py-self` + `streaming/golive.py` + compat shims) |
| `Slopsoil.Services` | Jellyfin + SyncPlay clients (`services/`) |
| `Slopsoil.Streaming` | FFmpeg video player, audio sender, engine (`streaming/`) |
| `Slopsoil.Commands` | Discord commands (`cogs/`) |
| `Slopsoil.Host` | entry point (`bot.py`) |

Project references enforce the constitution's layer rules: `Services` depends only on `Common`;
`Streaming` on `Discord` + `Common`; only `Commands` sees everything.

## Running the go-live spike (T013)

The test-pattern spike checks the whole send path against real Discord: gateway, voice, go-live,
RTP, transport crypto and DAVE. It streams FFmpeg `testsrc2` (1280×720, 30 fps) with a 440 Hz tone.

No .NET image is published yet (`latest` stays Python until the parity checklist passes), so build it from the repo root:

```bash
docker build -f dotnet/Dockerfile -t slopsoil-dotnet .
```

```bash
docker run --rm -e SLOPSOIL_SPIKE=testpattern -e DISCORD_TOKEN=... -e ALLOWED_USER_IDS=<your id> slopsoil-dotnet
```

1. Join a voice channel (ideally one with DAVE E2EE enabled).
2. Type `!join` in a text channel of that server. The bot joins and goes live.
3. Watch the stream. You should see a moving test card and hear a steady tone, with no stutter.
4. Type `!leave` to stop.

Every 10 s the log prints packets sent/dropped and `dave_ready`. Optional settings:

- `SLOPSOIL_SPIKE_VCODEC` picks the H.264 encoder (default `libopenh264`, e.g. `h264_vaapi` needs a VA-API device).
- `ALLOWED_USER_IDS` limits who can control the bot. When unset, anyone can.
